DiscorDrive — Stream Demo

Plays an encrypted file directly from Discord via Service Worker — no server decryption.

How to get fekRaw from your Node.js upload:
import { exportKey, toBase64 } from "@ddv4/processing";
console.log(toBase64(await exportKey(fek)));

The Service Worker must already be registered (run npm run dev:frontend and visit http://localhost:5173 first — the SW registers on first page load).
