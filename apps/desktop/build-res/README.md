Icons of the desktop app: the D of the web app's wordmark on the Cobalt accent (oklch(58% 0.2 256) = #0076ed),
cut into three strips (a file kept in pieces).

- `icon.png` 512x512 (Linux: AppImage, .deb), `icon.ico` 16-256 (Windows installer and window).
- `../static/tray.png` 32x32 and `tray@2x.png` 64x64 (HiDPI; Electron picks the @2x file next to it): a filled
  accent tile, so it reads the same on light and dark trays.
